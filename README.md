# .github

LG-Eureka 조직의 설정 저장소입니다.

조직 화면에 보이는 소개글은 이 파일이 아니라 [`profile/README.md`](profile/README.md) 입니다.
소개글을 고치려면 그 파일을 수정해 주세요.

```
.github/
├── README.md            이 파일 (저장소 설명, 조직 화면에는 보이지 않음)
└── profile/README.md    조직 화면에 표시되는 소개글
```

조직 전체에 적용할 이슈 · PR 템플릿이나 워크플로를 두려면 이 저장소에
`.github/ISSUE_TEMPLATE/`, `.github/workflows/` 를 추가하면 됩니다.
